# Milestone 1.7: Acceptance-Gate Approval and Notification Record

This artifact is the durable evidence that the Milestone 1.7 acceptance
gate passes from a clean disposable PostgreSQL through every workspace
quality check, runtime smoke case, privacy, deterministic ordering,
strict validation, lifecycle eligibility, and stale-request assertion.
It closes Issue #8 (`M1.7: Prove the complete Milestone 1 acceptance
gate`) and records the integration-owner approval required by
`AGENTS.md:127` for the shared-script changes below.

## Why this file exists

The M1.7 ticket requires the repository to demonstrate the complete
database-backed talent and offering search from a clean disposable
environment and to make the workspace-wide quality, privacy,
determinism, and dependency boundaries enforceable. Before this
artifact, the five acceptance criteria had no single reproducible
entry point and the "no external credentials" requirement had no
fail-closed enforcement. The gate composes the existing M1.1–M1.6
acceptance surface into a single command and adds an explicit
forbidden-dependency check so the boundary cannot regress.

## Forbidden-dependency surface

`scripts/check-forbidden-deps.mjs` rejects the following categories
of package and import specifier. The list is intentionally exhaustive
for the M1.7 boundary; later milestones (Matchmaker, uploads, payments)
are expected to remove the relevant entries through a documented ADR
rather than extend the allow-list.

- AI: `openai`, `@anthropic-ai/sdk`, `langchain`, `@langchain/core`,
  `google-generativeai`, `@google-cloud/vertexai`, `@google/adk`,
  `@google/genai`.
- Vector: `@pinecone-database/pinecone` (and any other
  `@pinecone-database/*` package).
- Redis: `redis`, `ioredis`, `@redis/client`.
- Object storage: `@aws-sdk/client-s3`, `@aws-sdk/lib-storage`,
  `@aws-sdk/s3-request-presigner`, `aws-sdk`,
  `@google-cloud/storage`, `@supabase/storage-js`, `pinata`,
  `@pinata/sdk`.
- Wallet: `ethers`, `wagmi`, `viem`, `web3`,
  `@walletconnect/web3-provider`.
- Blockchain: `@polkadot/api` (and any other `@polkadot/*` package),
  `@substrate/*`, `@solana/web3.js` (and any other `@solana/*`
  package), `near-api-js`.

The scanner checks every workspace `package.json` (root, `apps/*`,
`packages/*`), every resolved dependency declaration in
`pnpm-lock.yaml` (so transitive resolutions are caught even when no
top-level package declares them), and every TypeScript/JavaScript
source file under `apps/*/src`, `packages/*/src`, and `scripts/`.
Build artefacts (`node_modules/`, `dist/`, `.next/`, `.next-dev/`,
`test-results/`, `playwright-report/`) and the generated Prisma
client output (`packages/db/src/generated/`) are excluded because they
are produced from already-vetted inputs.

## How to run the gate

```bash
# Disposable test PostgreSQL must be reachable on port 5433.
docker compose -f docker-compose.test.yml up -d
pnpm acceptance-gate
```

The orchestrator runs the eight steps in dependency order and exits
non-zero on the first failure. The terminal output ends with
`READY FOR CODEX REVIEW.` on success.
