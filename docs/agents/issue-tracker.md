# Issue tracker: GitHub

Issues and PRDs for this repository live in GitHub Issues for the repository identified by the
configured `origin` remote. Use the `gh` CLI for issue operations.

## Conventions

- Publish a specification with `gh issue create`.
- Read full issue context with `gh issue view <number> --comments`.
- Apply triage labels with `gh issue edit <number> --add-label <label>`.
- Pull requests are not treated as a triage request surface.
